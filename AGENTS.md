# AGENTS.md

The Claude desktop app is unsupported: its Code tab does not draw `PromptHint`.

## Check

```sh
claude plugin validate .
claude plugin test .
```

CI runs both on Claude Code 2.1.312 (Node 22). `main` requires the `check` status. Raise the pin only on purpose.

## Hooks

- `hooks/hooks.json` loads `hooks/register.tsx` only. `hooks/speed.tsx` and `hooks/spinner.tsx` are Client modules. Keep them out of `hooks.json`.
- Register each event once. A second `on` of the same event throws.
- Spell `on`, `$`, `$.env` and `$.state` literally. Pass `$` only to module-level functions.
- No `import()`, `require`, Node or DOM. Use `$.process`, `$.http`, `$.store` and `$.clock`.
- `/reload-plugins` resets module state without `session.start`, so the first render calls `load($)`.
- Animate in Client modules. Hint-line redraws stop at 30 a second, the surface clock does not.
- Colors come from `ansi256(n)` with n below 16 on the terminal, or theme keys elsewhere. Never hex.

## Types

`.claude-plugin/types` is generated by `claude --plugin-dir .` and gitignored. Do not edit or commit it.

## Ship

- Conventional Commits. One PR per change, CI green, rebase merge.
- Bump `version` in `.claude-plugin/plugin.json` on a behavior change.
- Comments say why, never what.
- README images come from `tests/screenshots.test.ts`. The `screenshots` workflow renders them on `main` and pushes them to the `screenshots` branch.
- Keep each file's line endings. Source files and `plugin.json` are CRLF. Other JSON and YAML files are LF.
